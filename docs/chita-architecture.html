chita Architecture

A local terminal coding agent — single binary, eval-driven, audit-friendly

UI layer

  • • CLI --print for one-shot tasks
  • • TUI (pi-tui) for interactive sessions

Agent core

  • • Agent loop state machine with a done() hard gate
  • • Tool registry, context compaction, subagents, /goal judge

Capabilities

  • • OpenAI-compatible AI provider (remote)
  • • MCP servers register tools into the registry
  • • Skills assemble prompts locally

Storage

  • • Tape-first JSONL is the source of truth
  • • SQLite is only an index layer
  • • Four-layer memory
